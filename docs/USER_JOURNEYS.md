# Recorridos de usuario

## Crear y editar

1. La persona crea una presentación local desde Studio.
2. Define título, titular, slug, tema y metadatos.
3. Añade, ordena, duplica o elimina escenas; cada una usa layout y bloques permitidos.
4. Incorpora recursos validados y notas privadas.
5. Studio guarda el documento fuente y permite exportarlo.

## Previsualizar, ensayar y presentar

1. Studio abre una previsualización adaptable mediante Player.
2. La persona comprueba móvil, tablet o escritorio y corrige recursos o estructura.
3. Presenter muestra escena actual, siguiente, notas, progreso y tiempo.
4. La audiencia solo recibe PublicPresentationDocument; nunca notas ni historial editorial.

## Validar y publicar

1. Laboratory revisa contrato, recursos, accesibilidad, rendimiento, privacidad y compatibilidad.
2. Publisher crea PublicBundle, excluyendo datos privados y no utilizados.
3. PublishAdapter valida el destino, publica y devuelve URL estable y, si existe, URL versionada.
4. La persona comparte la URL o su código QR.

## Actualizar, revertir y abrir

1. Una actualización genera una nueva release sin reemplazar destructivamente la anterior.
2. La URL estable representa la release activa.
3. Una reversión selecciona una release válida previa y queda trazada.
4. La audiencia abre la URL en Player, sin cuenta ni acceso al editor.
