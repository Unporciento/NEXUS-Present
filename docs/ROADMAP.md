# Roadmap

Fase 5B incorporó formularios guiados, lista de escenas y edición estructurada. Fase 5C implementó validación y preview seguro con el Player real. Fase 5D implementa exportación JSON local determinista y permanece en revisión visual. Onboarding, ayuda, identidad final, footer, accesibilidad y responsive de cierre corresponden a 5E.

Refinamientos reservados: nombres amigables para tipos técnicos, unificación de “preview” y “vista previa”, scrolls internos, copyright del Player embebido y futuro empaquetado de assets y videos.

La implementación se detiene tras cada bloque 5A–5E para aprobación. Publicación, PWA, cuentas, sincronización y colaboración no pertenecen a esta fase.
