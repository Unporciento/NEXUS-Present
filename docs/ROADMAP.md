# Roadmap

Fase 5 planificada: Studio mínimo guiado y exportación local. La matriz de pruebas cubre creación, metadatos, cada escena, adición, eliminación confirmada, orden, tema, diagnósticos por campo, preview, exclusión privada, exportación, teclado, movimiento reducido, destrucción y futuro undo/redo.

La implementación se detiene tras cada bloque 5A–5E para aprobación. Publicación, PWA, cuentas, sincronización y colaboración no pertenecen a esta fase.
