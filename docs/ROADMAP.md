# Roadmap

Fase 5B incorporó formularios guiados, lista de escenas y edición estructurada. Fase 5C implementa validación y preview seguro con el Player real; permanece en revisión de rama. Exportación local corresponde a 5D; onboarding, ayuda, identidad final, footer, accesibilidad y responsive de cierre a 5E.

La implementación se detiene tras cada bloque 5A–5E para aprobación. Publicación, PWA, cuentas, sincronización y colaboración no pertenecen a esta fase.
