# Roadmap

Fase 5B incorpora formularios guiados, lista de escenas y edición estructurada. Preview corresponde a 5C; exportación local a 5D; onboarding, ayuda, identidad final, footer, accesibilidad y responsive de cierre a 5E.

La implementación se detiene tras cada bloque 5A–5E para aprobación. Publicación, PWA, cuentas, sincronización y colaboración no pertenecen a esta fase.
