# Preguntas frecuentes

## ¿Dónde están mis presentaciones?

En el almacenamiento local del navegador. Descarga un respaldo antes de limpiar datos o cambiar de dispositivo.

## ¿JSON o paquete portable?

JSON intercambia el documento público. El ZIP añade assets usados y Player; se abre mediante servidor HTTP.

## ¿NEXUS sube mis archivos?

No. Esta candidata no posee backend, nube ni telemetría.

## ¿Por qué un video no se reproduce?

El contenedor puede ser compatible y el codec no. NEXUS muestra fallback y permite continuar; no transcodifica.
